10.378 focos de incêndio. Seis maneiras de colocá-los em ordem.

São os focos que o satélite de referência do INPE detectou no estado de São Paulo em 2023 e 2024. O sistema os ordena por data, bioma e município com seis algoritmos escritos pelo grupo e conta cada comparação e cada troca que eles fazem.

Objetivo

Organizar a base de focos de incêndio do INPE por data, bioma e município, informando a cada solicitação quantas operações foram realizadas. Os seis algoritmos foram implementados à mão, sem os métodos de ordenação prontos do Java.

Incêndios comprometem a biodiversidade e alteram o clima, e o monitoramento por satélite gera muitos dados. Ordenar é a primeira etapa para analisá-los: dados organizados são o ponto de partida para técnicas de aprendizado de máquina que classificam áreas atingidas ou preveem padrões de queimadas.

Dados

Arquivos CSV do Programa Queimadas do INPE, na série do satélite de referência, que usa o mesmo satélite em todos os anos para permitir comparações. Estado de São Paulo, 2023 e 2024.

O back-end é escrito em Java 21, em camadas com uma responsabilidade cada. O painel só exibe o que a API devolve: nenhuma ordenação acontece no navegador.

Medição

Comparações
Cada vez que o algoritmo pergunta se um foco vem antes do outro. O comparador é envolvido por outro que conta as chamadas (padrão Decorator).
Trocas
Cada vez que um elemento muda de posição: uma troca, um deslocamento (Insertion) ou uma cópia (Merge).
Tempo
Medido com System.nanoTime(). Varia de um computador para outro; por isso a contagem de operações é a medida principal.
Mesma entrada
Cada ordenação recebe uma cópia dos dados originais, então nenhum algoritmo começa com a lista já ordenada.

Critérios

Data vai da detecção mais antiga para a mais recente. Bioma e município seguem a ordem alfabética do português, em que "Águas da Prata" fica junto dos nomes com A e não depois do Z, e desempatam pela data.

Esses empates mostram a diferença entre algoritmos estáveis, que mantêm a ordem original dos elementos iguais, e os que não mantêm.
